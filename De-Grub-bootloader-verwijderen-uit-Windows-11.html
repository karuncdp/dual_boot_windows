De GRUB-bootloader verwijderen uit Windows 11

Zie je bij elke start van je pc nog steeds het GRUB-menu, ook nadat je Ubuntu of Linux hebt verwijderd? Deze handleiding laat zien hoe je GRUB volledig verwijdert en Windows 11 weer schoon laat opstarten.

Geen hulpprogramma's van derden · Stap voor stap · Leestijd: 8 minuten

Het verwijderen van Linux uit een dual-boot-opstelling herstelt de Windows Boot Manager niet automatisch.

Elke stap bevat duidelijke instructies en schermafbeeldingen, zodat je de procedure ook zonder specialistische kennis veilig kunt volgen.

Stap 1

De gereserveerde ruimte voor Ubuntu verwijderen

Open Schijfbeheer en verwijder de Linux-partitie. Druk op Windows + X en klik op Schijfbeheer, of zoek ernaar in het startmenu.

De Linux-partitie heeft geen stationsletter en wordt meestal weergegeven als RAW of als een onbekend bestandssysteem. Ze kan ook verschijnen als een kleine partitie met alleen het label „Linux” of zonder label.

  1. Klik met de rechtermuisknop op de Linux-partitie.
  2. Selecteer Volume verwijderen.
  3. Bevestig wanneer daarom wordt gevraagd.
Opmerking: Heb je een aparte Linux-swappartitie (meestal 2–8 GB), verwijder die dan ook.
Stap 2

De ruimte opnieuw aan Windows toewijzen

Klik met de rechtermuisknop op station C: en kies Volume uitbreiden → Volgende → Volgende → Voltooien.

Opmerking: Je kunt niet-toegewezen ruimte alleen aan een station toevoegen als die ruimte zich rechts van het station bevindt, niet links.
Stap 3

Een stationsletter toewijzen aan de EFI-partitie

De EFI-partitie is een kleine, verborgen partitie waarin bootloaderbestanden, waaronder GRUB, zijn opgeslagen. Windows verbergt deze standaard. Open de Opdrachtprompt als administrator en voer deze opdrachten uit:

C:\> diskpart DISKPART> list disk DISKPART> select disk 0 DISKPART> list partition DISKPART> select partition X DISKPART> assign letter=Z
Tip: Heb je meer dan één schijf, gebruik dan list disk om te controleren of je op Schijf 0 (je belangrijkste Windows-schijf) werkt.
Stap 4

De Ubuntu-bootloaderbestanden uit de EFI-partitie verwijderen

Navigeer nu naar de EFI-partitie en verwijder de Ubuntu-gerelateerde bootloadermap.

  1. Druk op Ctrl + Shift + Esc om Taakbeheer te openen.
  2. Klik op Bestand → Nieuwe taak uitvoeren.
  3. Typ explorer.exe, vink „Deze taak met beheerdersrechten maken” aan en klik op OK.
  4. Ga in Verkenner naar Deze pc → Z: → EFI.
  5. Zoek de map ubuntu en verwijder deze.
Belangrijk: Verwijder alleen de map ubuntu. Verwijder niet de map Microsoft; anders kan Windows niet meer opstarten.
Stap 5

De tijdelijke stationsletter verwijderen

Laat de EFI-partitie niet toegankelijk. Ga terug naar de Opdrachtprompt en verwijder de letter die je hebt toegewezen:

DISKPART> select volume Z DISKPART> remove letter=Z
Gereed: De EFI-partitie is weer verborgen en je systeem start schoon op in Windows 11.

Veelgestelde vragen

Is het veilig om GRUB uit Windows 11 te verwijderen?

Ja, zolang Linux al is verwijderd en je alleen de map ubuntu wist. Laat de map Microsoft altijd staan.

Waarom verschijnt GRUB nog na het verwijderen van Ubuntu?

De Ubuntu-partitie en de GRUB-bestanden in de verborgen EFI-partitie zijn verschillend. Daarom moet de Ubuntu-map in EFI ook worden verwijderd.

Kan ik GRUB verwijderen zonder Linux te verwijderen?

Technisch kan dat, maar het wordt niet aanbevolen. Zonder GRUB kun je de Linux-installatie mogelijk niet meer starten.

GRUB is verwijderd.

Je pc start nu rechtstreeks op in Windows 11. De schijf is opgeruimd en er zijn geen Linux-bootloaderresten meer.
